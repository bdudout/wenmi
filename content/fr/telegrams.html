Les télégrammes, un par un

Les dix-sept télégrammes de 1916 lus à ce jour, sur les deux canaux : les lettres telles qu'elles ont été lues sur les formulaires, le code et le caractère obtenus, le degré de confiance de chaque caractère, et, pour les passages douteux, les erreurs qui pourraient les expliquer.

Transcriptions de Brice Dudout (lectures humaines à l'aveugle) ; analyse avec Claude (Anthropic).

Comment lire cette page

Chaque télégramme est donné en trois couches : les lettres lues sur la copie japonaise (groupées par dix, comme sur le formulaire), puis, case par case, les deux syllabes, le code télégraphique qu'elles donnent sous la clé du canal (G0 ou Y0), et le caractère chinois correspondant.

報 sûr : caractère attendu dans un texte de ce genre 粤 rare mais confirmé (date du formulaire, mot relu à l'image, nom, variante graphique) 睟 douteux : caractère improbable à cet endroit · illisible ou syllabe hors grille

« Sûr » veut dire que le caractère est plausible pour le modèle de langue et cohérent avec le reste ; cela ne garantit pas chaque lettre. Un caractère « douteux » peut aussi être juste (un nom propre, un terme technique rare) : c'est un signal, pas un verdict.

D'où peuvent venir les erreurs ?

Entre le texte de Zhao Shen et notre lecture, chaque lettre a franchi trois étapes, chacune avec ses erreurs typiques :

  1. La transmission Morse. Les lettres voyagent en points et en traits. Un signe perdu, ajouté ou inversé change la lettre : e (·) devient i (··), a (·−) devient e (·) ou w (·−−), etc.
  2. La copie japonaise. L'employé recopie à la main des mots qui n'ont aucun sens pour lui. Certaines lettres de son écriture se confondent : g/q, x/d, u/n, a/o, k/h, f/b… (paires relevées à l'image pendant l'enquête).
  3. Notre lecture. Les mêmes confusions jouent une seconde fois, cent dix ans plus tard, sur le scan.

Pour chaque code douteux, l'ordinateur essaie donc toutes les variantes qui changent une seule lettre par l'un de ces mécanismes, garde celles qui donnent une syllabe valide, et les classe selon ce qu'en pense le modèle de langue (le nombre indiqué est le gain de vraisemblance, en logarithme : plus il est grand, plus la variante « sonne » chinois à cet endroit). Ce sont des pistes, pas des corrections : le texte affiché n'est jamais modifié.

Le cas qui valide la méthode

Le télégramme 0416b (19 juillet) finit par un code sans sens, 4210. Le même jour, son jumeau 0416a, envoyé par l'autre canal, finit par 伸皓, « Shen, le 19 ». En cherchant une erreur d'une seule lettre, on trouve exactement : xifa au lieu de xefa. C'est à la fois une erreur Morse plausible (·· au lieu de ·) et une confusion de copie (i/e). La correction 皓 se lit alors sans difficulté.

À l'inverse, le télégramme 0386 se termine par 卄 (« 20 ») alors que le formulaire porte le 30 juin. Pour obtenir 卅 (« 30 »), il faudrait changer un p en n : ce n'est ni une erreur Morse d'un signe ni une confusion de copie relevée. L'écart reste inexpliqué.
